SERVICES — 服務項目
解鎖

Bootloader 解鎖／降級

刷機第一步，解鎖手機的開機引導程式鎖，為後續安裝 Root 做準備；解鎖後也可用於系統版本降級。

ROOT

Root 安裝與隱藏套件

安裝 Root 權限框架，並搭配隱藏套件安裝，避免銀行、薪資轉帳等 App 偵測到裝置已 Root 而無法使用。點看安裝套件 →

飛人

Pokémon GO 飛人軟體安裝

協助安裝 GPS 定位模擬（飛人）軟體，可虛擬移動、遠端抓寶，並搭配 Hide Mock Location 隱藏偵測。⚠️ 此類工具違反遊戲官方服務條款，使用有帳號被封鎖的風險，請自行評估。

救援

磚機救援／系統修復

手機刷機失敗、系統損毀無法開機，提供救援嘗試。多數狀況比照統一價，狀況較複雜的案例將個別評估報價。

售後

常用軟體與售後支援

常見問題自助排除、實際案例整理，以及常用軟體最新版本更新連結。前往售後支援頁 →

PROCESS — 服務流程

  • 收件確認

    拍照記錄手機外觀，確認目前系統版本，作為前後對照依據。

  • 告知完工時間

    收到手機半小時內，確認機況並告知確切完工時間，避免反覆詢問進度。

  • 服務執行（依實際需求）

    依客戶需求進行對應服務，如解鎖、Root 安裝、隱藏套件安裝、磚機救援等。

  • 功能測試

    測試裝置可正常使用，依需求提供完工照片或影片。

  • 交付結案

    確認收款後面交或回寄，完成交易。

TERMS — 服務條款
📋 服務前確認
  1. 手機須為本人所有（非分期未繳清、非贓機、非共有財產）
  2. 刷機有磚機風險，無法保證 100% 成功；資料將被清除，請自行備份，恕不負責資料遺失
  3. 刷機後原廠保固是否失效由原廠認定，與本服務無關
  4. 請提供正確機型與系統版本，資訊有誤致刷機失敗者，不予退費
  5. 寄件請自行加保，物流遺失或損壞恕不負責
🚨 責任範圍
  1. 操作失誤致磚機，會盡力搶救，能否修復由本人評估後告知
  2. 手機本身硬體瑕疵或非官方維修痕跡致刷機失敗，不在賠償範圍
  3. 服務僅限「刷機、Root、安裝常用工具」本身，不涉及手機原有功能、外觀、電池健康度
🛡️ 保固說明
  1. 完工後 1 個月內，如不小心自行移除 Root、軟體無法使用、或裝置無法正常開機等狀況，可免費協助處理，買家僅需負擔來回運費
  2. 實際處理方式依工作室收到裝置後的檢測結果為準；若診斷為完全黑屏、需透過 9008 等工程模式救援的嚴重磚機情況，不在此免費範圍，將另行報價
  3. 保固不包含非本工作室操作造成的問題（如客戶自行刷入其他系統、拆機、泡水、摔損等）
  4. 申請保固需提供完工訂單編號，工作室將核對收件紀錄（含裝置 IMEI／序號）確認為同一台裝置
完整條款請於下單前詳閱，下單即視為同意。
